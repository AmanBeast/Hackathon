Design and redesign the homepage of Tutedude, an Indian online learning platform focused on career-oriented courses in technology, AI/ML, development, data, design, finance, marketing, cybersecurity, cloud and other professional skills.

REFERENCE WEBSITE:
https://tutedude.com

IMPORTANT:
Do not simply clone the existing website.
Use the existing website only to understand:
- Brand/message
- Business model
- Course categories
- Refund mechanism
- Audience
- Trust signals
- Existing content hierarchy

Create a modern, premium, conversion-focused EdTech homepage with a strong emphasis on the unique "100% Refund on Course Completion" proposition.

==================================================
CORE BRAND MESSAGE
==================================================

The primary message should be:

"Learn seriously. Complete the course. Get your eligible course fee back."

Tutedude's differentiation is that students pay an enrollment/commitment fee and can receive a 100% refund after satisfying the applicable course completion requirements within the specified challenge/refund period.

The website should make this concept immediately understandable.

Avoid making the refund offer feel like a cheap discount.

Position it as:

COMMIT → LEARN → COMPLETE → GET REFUNDED

The product should feel:
- Trustworthy
- Career-focused
- Modern
- Student-friendly
- Premium
- Outcome-oriented
- Slightly energetic
- Not overly corporate
- Not like a generic Udemy clone

==================================================
TARGET USERS
==================================================

Primary audience:
- College students
- Fresh graduates
- Early-career professionals
- Career switchers
- People wanting practical tech/business skills

Their concerns:
- "Will this course actually help me?"
- "Is this worth my money?"
- "Will I get mentorship?"
- "Will I actually complete the course?"
- "Will I get practical projects?"
- "What happens if I complete everything?"
- "Is the refund real?"
- "Can I learn while studying/working?"

The UI should answer these questions progressively as the user scrolls.

==================================================
DESIGN DIRECTION
==================================================

Create a premium modern EdTech interface.

Visual style:
- Clean white/light background
- Dark navy/charcoal primary typography
- Use Tutedude's existing brand identity as inspiration but modernize it
- Strong accent color for CTA and refund-related highlights
- Large typography
- Generous whitespace
- Rounded cards
- Soft shadows
- Subtle gradients
- Modern icons
- High-quality student/career imagery
- Subtle motion and micro-interactions

Avoid:
- Excessive gradients
- Too many colors
- Dense walls of text
- Generic stock-photo-heavy layouts
- Excessive cards everywhere
- Overly childish education aesthetics

Use a visual language similar to a premium startup/SaaS product combined with a modern EdTech platform.

==================================================
UX PRINCIPLES
==================================================

The user journey should be:

LAND
↓
UNDERSTAND THE REFUND MODEL
↓
TRUST THE BRAND
↓
DISCOVER A CAREER PATH
↓
EXPLORE COURSE
↓
UNDERSTAND OUTCOME
↓
CHECK REFUND CONDITIONS
↓
ENROLL

Every major section should move the user toward one of these decisions.

Use progressive disclosure rather than dumping every detail above the fold.

The homepage should feel like a modern career platform rather than a traditional online-course marketplace.

Create polished UI components, realistic content, hover states, loading states, empty states, mobile layouts and subtle micro-interactions.

Use accessible contrast, consistent spacing, clear hierarchy and a reusable design system.
