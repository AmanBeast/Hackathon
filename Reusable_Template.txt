Design a reusable, production-quality course detail page template for Tutedude.

REFERENCE:
https://tutedude.com

The design must NOT be created for one specific course only.

It must function as a UNIVERSAL COURSE PAGE TEMPLATE that an admin/CMS can populate for:

- Python
- Data Science
- Machine Learning
- React
- MERN Stack
- UI/UX
- DSA
- Cybersecurity
- Finance
- Marketing
- DevOps
- Cloud
- Video Editing
- Any future Tutedude course

The visual structure must remain consistent while course-specific content is dynamically replaced.

==================================================
PRIMARY OBJECTIVE
==================================================

The course page must answer these questions in order:

1. What will I learn?
2. Who is this course for?
3. What will I be able to build/do?
4. How long is it?
5. Who teaches it?
6. What support do I get?
7. How does the refund opportunity work?
8. What exactly do I need to complete to qualify?
9. What do previous learners say?
10. What do I get after completing it?
11. Why should I enroll?

The page should convert interest into enrollment without feeling like an aggressive sales page.

Use the same visual language as the redesigned Tutedude homepage.

Style:
- Premium modern EdTech

- Trustworthy
- Career-oriented
- High information clarity
- Strong typography
- White/light neutral background
- Dark text
- Tutedude brand accent
- Rounded cards
- Subtle shadows
- Minimal gradients
- High-quality icons
- Strong CTA hierarchy

ADMIN / CMS TEMPLATE REQUIREMENT
==================================================

The most important requirement:

This page is a TEMPLATE.

Create the visual system so that an admin can create a new course without redesigning the page.

Think of the page as a component system.

Create reusable components:

CourseHero
CourseStats
LearningOutcomes
CourseOutcomes
Curriculum
Projects
Assignments
RefundJourney
Instructor
Mentorship
Audience
Prerequisites
TechStack
Certificate
Testimonials
FAQ
EnrollmentCTA

Each component receives dynamic data.

Example conceptual data structure:

course:
{
 title,
 category,
 subtitle,
 description,
 thumbnail,
 price,
 originalPrice,
 rating,
 learners,
 duration,
 modules,
 outcomes,
 projects,
 assignments,
 refundPolicy,
 refundPeriod,
 refundRequirements,
 instructor,
 mentors,
 prerequisites,
 technologies,
 certificate,
 testimonials,
 faqs
}

The UI must gracefully handle:

- Missing instructor
- No projects
- No testimonials
- Different number of modules
- Different refund periods
- Different pricing
- Different course lengths
- Different prerequisites
- Different technologies
- Courses with/without mentorship
- Courses with different completion requirements

Do not create empty-looking sections.

If a component has no data, hide the section automatically.

The final course page should feel like:

"Coursera-level information architecture
+
modern startup UI
+
career-focused EdTech

It should be substantially more polished, structured and trustworthy than a conventional course landing page.

DO NOT DESIGN A ONE-OFF COURSE PAGE.
